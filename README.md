# 命理风水 · 八字四柱排盘

**中文**（本页） | **English** [README.en.md](README.en.md)

> 依据**出生地**与**出生年月日时**，在浏览器本地排出四柱八字、五行喜忌与八宅风水方位。

**🌐 在线使用：<https://xudaniel.github.io/mingli-fengshui/>**（支持安装为 PWA，离线可用）

[![CI & Deploy](https://github.com/xudaniel/mingli-fengshui/actions/workflows/deploy.yml/badge.svg)](https://github.com/xudaniel/mingli-fengshui/actions/workflows/deploy.yml)

一个纯前端的中国传统命理排盘应用：输入出生信息即可得到完整的四柱干支（含藏干十神）、加权五行强弱与喜用神分析、五行调理建议、八宅命卦吉凶方位图、大运流年、犯太岁提醒、性格与事业解读、人生五行走势图，并支持合婚配对、个人择吉日历与手机实景罗盘。所有计算都在浏览器本地完成，不依赖任何后端；界面支持中英双语。

## ✨ 功能特性

### 🕐 真太阳时校正
传统八字以太阳在当地天空的位置定时辰，而非行政时区的钟表时间。本应用会：

- 按出生地**经度**校正（每偏离时区中央经线 1° 约合 4 分钟）；
- 可选叠加**均时差**（太阳时与平太阳时的季节性偏差，全年在约 ±16 分钟内摆动，采用 Spencer 1971 近似式）；
- 校正前后的时刻都会在结果中明示，方便与其他排盘工具对照。

对乌鲁木齐（东经 87.6°，用 UTC+8 的钟表时间）这类经度与时区差异大的地区，校正可达约两小时，足以改变时柱甚至日柱。

此外还内置**历史时制提醒**：出生时刻落在中国夏令时期间（1986–1991 年，钟表拨快 1 小时）时自动警告并可一键回拨 1 小时；1949 年前出生则提示当时的昆仑/新藏/陇蜀/中原/长白五时区背景。

### 🕛 时辰不详模式
不确定出生时辰？勾选「时辰不详」后，应用会对十二时辰逐一排盘，诚实区分：

- **与时辰无关的稳定结论**：年月日三柱、生肖、星座、命卦、调候用神；
- **随时辰变化的敏感结论**：完整展示十二时辰各自的时柱干支、身强身弱判定与喜用神，并给出十二时辰中最多数的判定与「无论哪个时辰都成立」的喜用神。

### 📜 四柱八字
排盘核心由久经验证的开源库 [lunar-javascript](https://github.com/6tail/lunar-javascript) 依二十四节气精确推算：

- 年、月、日、时四柱干支，天干地支均按五行着色；
- 每柱**藏干**（本气/中气/余气）及其对应**十神**；
- **纳音**、**空亡**、**胎元**、**命宫**、**身宫**；
- 农历日期、**生肖**（以立春为界）与星座；
- **大运**（起运岁数与每步十年的干支）、当前**流年**及其与喜忌的对照提示；点击任一大运可展开该十年逐年的**流年**详情，按喜忌着色并高亮今年。

### ⚖️ 五行强弱与喜用神（简化子平法）
比常见的「数一数八个字」更进一步的加权分析：

- 天干各计 100 分；地支按藏干拆分 100 分（本气 60 / 中气 30 / 余气 10，两藏干为 70/30）；
- **月令（月支）整体乘以 1.5 倍**，体现「月令司权、得令者旺」；
- 同党 =「与日主同行（比劫）+ 生日主之行（印星）」，占比 ≥55% 判**身强**、≤45% 判**身弱**、其余**中和**；
- 身弱喜印比生扶，身强喜食伤、财、官杀克泄耗，中和补最弱之行；
- 另依《穷通宝鉴》通行简表给出**调候用神**（寒暖燥湿优先），与扶抑结论相左时并列展示并说明取舍；
- 结果附有完整的中文推理说明与身强身弱刻度表，判断过程公开透明。

### 🔗 地支关系（合冲刑害）
自动检测四柱地支之间的**六合、三合（含半合）、三会、相冲、相刑（含自刑与三刑）、相害**，逐条列出参与柱位、合化五行与通俗含义，并在柱卡片上以徽标标注，让命盘读作一个互动的整体而非八个孤立的字。

### 🍑 神煞（含桃花）
自动查得命盘中的**天乙贵人、文昌、禄神、羊刃、驿马、将星、华盖**与**桃花**（按年支/日支分别查三合局沐浴位），逐条列出落于哪一柱及通俗含义，吉凶以颜色区分。

### 🧭 八宅命卦 · 吉凶方位
风水部分采用与出生信息直接挂钩的经典**八宅派**体系：

- 由**立春为界**的出生年与性别推得本命卦（坎/坤/震/巽/乾/兑/艮/离）；
- 判定**东四命/西四命**及宜居宅向；
- 以罗盘图 + 明细表展示**四吉方**（生气、天医、延年、伏位）与**四凶方**（祸害、五鬼、六煞、绝命），并注明每方适合的功能空间（大门、卧室、书房、卫浴等）。

### 🏠 住宅宅卦匹配
选择住宅朝向（大门/采光面），应用推算出对应**宅卦**（坐山定卦），与您的命卦比对东四命/西四命是否相配，并给出各房间的方位建议——把八宅体系从「个人专属」延伸到「个人 + 住宅」的实际应用场景。

### 🧭📱 手机实景罗盘
移动设备上，点击「实景罗盘」可读取方向传感器，罗盘随手机朝向实时旋转，高亮当前正对的吉凶方位，附磁偏角与传感器误差提示。

### 🐯 犯太岁提醒
对照未来 12 年与本命年支的关系，标注**值太岁、冲太岁、刑太岁、害太岁、破太岁**及对应年份，附通俗解释。

### 🧑 性格与事业解读
规则驱动（非 AI）的简化解读：日主天干性格、命局中最旺的十神及其性格倾向、身强身弱的扬长避短建议，以及依喜用神映射的行业方向参考。

### 📈 人生五行走势图
以折线图直观展示每年干支与喜用神的契合度（-3 至 +3），底色分段标出各步大运，一眼看出人生各阶段的大致顺逆。

### 💑 合婚配对分析
选择两份已保存的命盘档案，从**日干五合、日支合冲刑害、生肖关系、五行互补、命卦分组**五个维度给出简化的民俗式合婚参考与 0–100 综合评分。

### 📅 个人择吉日历
按月历浏览每一天，结合您的命盘对日柱冲合、喜用神天干进行个性化打分，并叠加 lunar-javascript 内置的每日宜忌，可按「签约/搬家/开业/嫁娶」筛选推荐日期。

### 🎨 五行调理建议
针对喜用之行给出可操作的日常建议：方位、颜色、材质、数字、旺季与家居布置宜忌。

### 🗺️ 出生地定位
- 内置中国各省会/主要城市及常见海外城市共 50+ 条精选坐标；
- 陌生地名可通过 OpenStreetMap Nominatim 在线搜索（应用中唯一的网络请求，仅发送地名文本）；
- 经度与时区随时可手动修改，适配历史时区差异。

### 💾 多命盘档案
- 排盘后自动保存为**可命名档案**（不止最近几条，支持重命名与删除）；
- 支持导出全部档案为 JSON 备份、导入合并（按内容自动去重）；
- 合婚配对与择吉日历均直接从已保存档案中选择。

### 🌐 中英双语 · 📲 离线安装
- 界面支持中文/English 一键切换（记住偏好，默认中文）；干支、十神等术语在英文界面下附拼音与通行英译；
- 支持安装到桌面/主屏幕，离线使用（PWA，Service Worker 预缓存）；
- 深色典雅界面，桌面/移动端自适应；
- 应用内「关于」页说明算法与隐私政策。

### 🔗 分享与导出
- **复制结果**一键把整份排盘摘要复制为纯文本；
- **复制链接**把出生信息编码进 URL，接收端打开即在其浏览器本地重新排盘，不经过任何服务器；
- **保存图片**一键导出竖版长图（四柱、五行、命卦、大运），适合微信等以图片为主的社交场景分享。

## 🚀 快速开始

需要 Node.js 18+。

```bash
# 安装依赖
npm install

# 本地开发（默认 http://localhost:5173）
npm run dev

# 生产构建（输出至 dist/）
npm run build

# 预览生产构建
npm run preview

# 运行测试（vitest，150+ 用例覆盖核心算法与已知命盘快照）
npm test
```

构建产物是纯静态文件，可直接部署到 GitHub Pages、Vercel、Netlify 或任何静态服务器。本仓库每次推送到 `main` 会先跑类型检查与全部测试，通过后才自动部署到 GitHub Pages。

## 🔬 算法与取舍说明

| 环节 | 采用方法 | 说明 |
| --- | --- | --- |
| 干支推算 | lunar-javascript（节气精确到分钟） | 年柱以立春为界、月柱以节为界，晚子时按流派 2（23 点后日柱仍算当天，时柱按次日子时起） |
| 真太阳时 | 经度差 4 分/度 + Spencer 1971 均时差 | 可分别开关；历史时区（如民国时期五时区）需手动调整 UTC 偏移 |
| 历史时制 | 1986–1991 夏令时精确起止表（与 tzdata 一致） | 落入区间时警告并可一键回拨 1 小时；1949 年前出生提示五时区背景 |
| 五行强弱 | 藏干加权 + 月令 1.5 倍 + 同党占比 | 简化子平法；未纳入格局取用等高阶因素 |
| 喜用神 | 扶抑法 + 调候并列 | 身弱扶之、身强抑之、中和补最弱；调候依《穷通宝鉴》通行简表，两说相左时并列展示 |
| 地支关系 | 六合/三合/半合/三会/冲/刑/害 标准查表 | 仅展示盘面互动，暂不并入五行计分 |
| 命卦 | 通用数字根公式，年以立春为界 | 得 5 者男归坤、女归艮 |
| 宅卦 | 坐山（朝向正对面）对应后天八卦标准表 | 与命卦共用同一套游星表 |
| 风水方位 | 八宅派标准游星表 | 生气/天医/延年/伏位 + 祸害/五鬼/六煞/绝命 |
| 犯太岁 | 本命年支 vs 流年支的值/冲/刑/害/破查表 | 民俗参考，非严格命理推断 |
| 合婚评分 | 日干五合/日支关系/生肖关系/五行互补/命卦分组加权打分 | 0–100 分仅供排序参考，非专业合婚排盘 |
| 择吉打分 | 冲日柱 -3、刑害日柱 -2、六合 +1、喜用天干 +2/忌 -1 | 叠加 lunar-javascript 内置每日宜忌 |
| 时辰不详 | 十二时辰（以传统起始时刻为代表点）逐一排盘 | 区分稳定/敏感结论，不做单一武断判定 |
| 神煞/桃花 | 天乙贵人、文昌、禄神、羊刃按日干查表；驿马、将星、华盖、桃花按年支/日支查三合局固定位 | 静态查表法，仅供文化参考 |
| 打包体积 | lunar-javascript 单文件约 426KB（无法 tree-shaking），是主包体积的主因；合婚/日历/罗盘/图片导出等次要视图改用动态 `import()` 懒加载 | 已评估分叉/替换日历库，因排盘正确性风险过高而搁置，选择风险更低的代码分割方案 |

## ⚠️ 免责声明

本应用的所有输出基于公开的传统命理规则与透明的简化算法，**仅供传统文化学习、参考与娱乐**。完整的专业命理分析还需综合格局取用、干支合化对计分的影响等诸多因素，因人而异。请勿依据本应用的结果做出医疗、投资、婚姻等重大人生决定。

## 🔒 隐私

- 排盘计算 100% 在浏览器本地完成，出生信息不会上传到任何服务器；
- 命盘档案仅存于本机浏览器的 localStorage，可随时导出备份或一键清空；
- 仅当搜索内置列表之外的地名时，会向 OpenStreetMap Nominatim 公共服务发送该地名文本。
